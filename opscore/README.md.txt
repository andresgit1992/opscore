# ByMetal - Full Stack Management System

ERP-style management system built with FastAPI and MariaDB, designed to handle real business operations including quotations, purchase orders, payments, HR, and OCR document processing.

---

## 🚀 Overview

ByMetal is a modular full-stack system that centralizes operational workflows for industrial and logistics environments.

The system includes:

- User authentication and role management
- Quotations system
- Purchase orders tracking
- Payments and financial control
- HR (employees, categories, status)
- OCR processing for documents
- Real-time dashboards and analytics

---

## 🛠 Tech Stack

- Backend: FastAPI (Python)
- Database: MariaDB
- Frontend: HTML + TailwindCSS + Vanilla JS
- OCR: Tesseract
- Server: Debian + Uvicorn (systemd)

---

## ⚙️ Features

- Modular architecture
- REST API design
- Role-based access control (RBAC)
- Dynamic dashboards with statistics
- File upload and document processing
- Business workflow automation
- Multi-company support
